# Sang Pembawa Pelita

Gandra (24), seorang kurir malam dan penjaga pelita di galangan Bawah-Batavia, menemukan relik kuno **Pelita Jiwa** warisan Empu Aether. Bersama peretas sirkuit Tara Kirana, ia harus menghentikan rencana Lupa Corp yang ingin memadamkan jaringan perisai kota Bawah-Batavia.
