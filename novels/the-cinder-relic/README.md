# The Cinder Relic

Raka (25), seorang penempa tungku uap di Pesisir Kuno Neo-Batavia, secara tak sengaja membangkitkan **Cinder Relic**—relik bara tembaga gaib warisan Empu Aether yang merakit dirinya membalut lengan kanan Raka. Dengan kekuatan bara Aether, Raka menangkis ledakan uap musuh dan membakar sirkuit mekanis, namun relik tersebut menagih harga berupa demam panas fisik hebat setiap kali diaktifkan.
