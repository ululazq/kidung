# Serat Penempa Hampa

Arya Pradipta (24), seorang teknisi sirkuit perunggu dan peretas kompresor pneumatik di Stasiun 13 Bawah-Batavia, menemukan lempengan tembaga berukir simbol kuno di dalam peti rahasia laboratorium benteng. Lempengan tersebut adalah **Serat Penempa Hampa**—relik perisai gravitasi hampa warisan Empu Aether yang merakit dirinya secara otomatis membalut pergelangan tangan kanan Arya.
